# Website Alumni dan Kajian Rausyan Fikr

Aplikasi komunitas untuk data alumni, materi kajian bertingkat, laporan wilayah, serta tulisan dan galeri publik.

Mulai dari [peta dokumentasi pengembangan](docs/aturan_pengembangan/README.md). Dokumen tersebut menentukan acuan fungsi, keputusan, pekerjaan, risiko, prosedur, dan arsip.

- Pengguna/pengembang baru: [instalasi lokal](docs/aturan_pengembangan/SOP.md#2-instalasi-develop-baru).
- Mengerjakan perubahan: [AGENTS](AGENTS.md), lalu urutan baca pada peta dokumentasi.
- Memeriksa hasil dan pekerjaan tersisa: [TASK](docs/aturan_pengembangan/TASK.md#register-rfix).
- Menyiapkan lingkungan server: [runbook staging dan pemulihan](docs/aturan_pengembangan/RUNBOOK_STAGING_JALUR_B.md).

Kode, lockfile, dan konfigurasi runtime berada di repositori ini. Persetujuan deployment serta identitas/lisensi pemilik mengikuti keputusan yang dicatat pada dokumen pengembangan.
